Espacement, ombres & bordures

Ombres — offset hard

Pas de blur. L'ombre est un offset solide à 3px 3px. Le CTA primaire utilise l'accent rouge à la place.

Shadow hard
Shadow accent
--shadow-hard: 3px 3px 0 0 var(--ink); --shadow-accent: 3px 3px 0 0 var(--rouge); /* CTA primaires uniquement */

Au tap (:active), la carte se décale de 2px et l'ombre se réduit à 1px 1px — effet "appui" éditorial, jamais un scale.

Règles

  • Toujours bordure + offset shadow ensemble sur les cartes principales.
  • Jamais de blur, jamais d'ombre douce. L'élévation est graphique, pas physique.
  • Tap state : translate(2px, 2px) + shadow réduite à 1px 1px. Pas de scale.
  • Safe-area : env(safe-area-inset-top/bottom) sur headers et bottom nav.
  • Bottom sheets : max-h-[90dvh] flex flex-col + overflow-y-auto flex-1 + z-[60].
