Typographie

Deux polices, deux rôles. Cormorant Garamond italique porte la voix éditoriale — titres, citations, marginalia. Inter porte la fonction — UI, métriques, labels. Toutes les nuances "manuscrites" passent par l'italique du serif.

Système

Une paire serif éditorial + sans neutre. C'est tout.

DISPLAY
Cormorant Garamond
Poids : 500–600 · italique privilégié pour les titres et citations. Usages : H1 d'écran, nom de vin, big numbers du dashboard, filigrane, marginalia.
SANS
Inter
Poids : 400–700 · variantes tabular-nums pour les chiffres. Usages : UI body, labels tracés, métriques, millésimes, navigation.

Échelle

Toutes les tailles sont pensées pour le mobile (390px). Bigger is editorial.

Règles

  • Display = italic. Cormorant n'est jamais affiché en romain. L'italique porte la voix.
  • Sans = Inter. Pour la fonction. tabular-nums sur tout chiffre comptable.
  • Pas de "police manuscrite". Caveat a été abandonné — les marginalia passent par l'italique du serif.
  • text-wrap: balance sur titres, pretty sur citations & paragraphes.
  • Minimum 9px en sans + uppercase + tracking pour rester lisible.
